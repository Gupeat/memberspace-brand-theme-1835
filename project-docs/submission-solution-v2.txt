【S3-BRAND-001】会员空间平台 · 小程序主题设计变量与 TDesign 主题映射（rework v2.2.0）

一、交付范围
本单目标是把品牌规范落成可执行的小程序主题变量，并映射到 TDesign 小程序组件：色彩（品牌主色/辅助色/中性 10 阶/成功警告错误信息语义色）、字号 24/28/32/36/40/48rpx 与行高/字重、圆角 8/16/24rpx 与全圆、间距 16/24/32/48/64rpx、阴影 3 级、动效时长与缓动。交付 tokens.json（W3C DTCG）、theme.wxss、在线 Figma 变量集合、可导入 DTCG、1:1 对照表、对比度检查表、微信开发者工具截图、使用说明与可复现校验。

五、实现要点
1) tokens.json 是唯一真源；theme.wxss、miniprogram-demo/theme.wxss、demo/theme.css、Figma 变量 JSON/插件、DTCG 导入文件、对比度表、对照表全部由 build.py 生成，validate.py 拦截陈旧产物并逐字节比对。
2) theme.wxss 只保留 tdesign-miniprogram 1.18.0 实际消费的 64 个变量；未消费的 --td-line-height、--td-anim-duration-moderate、--td-anim-duration-slow、--td-anim-time-fn-ease-in 从映射移除，对应 token 仍保留，避免“官方名但组件不消费”的虚映射。
3) 对比度按 WCAG 2.1 相对亮度计算，仅把正文文字组合纳入 AC2；装饰色/禁用色不计入正文。该检查是颜色组合校验，不等同完整 UI 无障碍审计。
4) Figma 名称保留点号路径，不转成 “/” 分组，保证名称严格 1:1；在线文件已实际导入 74 变量并导出快照校验。插件按同名创建/更新，不删除既有变量；类型冲突跳过并提示，未匹配变量保留并报告。
5) tokens.json 本身就是嵌套 DTCG（DTCG 不允许点号作为扁平键），figma-import/Light 是同一结构的导入副本而非另一套数据；颜色为 sRGB，尺寸按 2rpx=1px 换算，动效 ms、字重 int，别名保留 {path}；Light.tokens.json 用于让 Figma mode 名为 Light。
