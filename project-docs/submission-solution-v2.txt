四、实现要点与边界处理
1) tokens.json 是唯一真源，theme.wxss、demo/theme.css、Figma 变量 JSON/插件、对比度表、对照表全部由 build.py 生成；validate.py 会拦截陈旧生成物。
2) TDesign 映射按 tdesign-miniprogram 1.18.0 实际消费核对：theme.wxss 保留 64 个实际消费变量；未消费的 --td-line-height、--td-anim-duration-moderate、--td-anim-duration-slow、--td-anim-time-fn-ease-in 已从映射移除，对应 token 仍保留，避免“名称官方但组件不消费”的虚映射。
3) 对比度按 WCAG 2.1 相对亮度计算，仅把正文文字组合纳入 AC2；装饰色/禁用色不计入正文，文档已标注。该检查是颜色组合校验，不等同完整 UI 无障碍审计。
4) Figma 名称保留 tokens.json 的点号路径，不转成 “/” 分组，保证名称严格 1:1；插件按同名创建/更新，**不删除集合内已有变量**；类型冲突跳过并提示，未匹配变量保留并报告，避免破坏用户既有变量。
